# WorkBuddy Token 监控看板

一个**纯本地、只读、不联网**的小工具：自动读取本机 WorkBuddy 的会话数据，实时画出每个任务的 token / 积分消耗折线图，并支持按「轮次」和「单步（每次工具调用）」两种粒度查看明细。

> 官方目前只提供「输入框旁的上下文占用快照」和「积分明细列表」，没有按任务聚合的时序可视化。这个看板把本地已有的原始数据接出来展示，不修改、不上传任何内容。

## 特性

- **启动即监控全机任务**：扫描 `~/.workbuddy/projects/*/*.jsonl`，之后增量读取，页面每 1.8 秒刷新；任务运行中曲线自己往右长。
- **左侧任务列表**：按最近活跃 / Token 总量 / 积分 / 轮次排序，支持搜索，实时活跃指示灯。
- **四条曲线可切**：
  - 累计 Token（输入、输出两条）
  - **单步 Token**：锯齿即上下文规模变化，能清楚看到上下文压缩（compaction）后回落的瞬间
  - 累计积分
  - 缓存命中率
- **按轮次分段**：图上按你发消息的轮次画色带与分隔线，悬停出十字线和明细。
- **明细区「逐轮 / 逐步骤」切换**：
  - 逐轮：每行一轮对话，含总 token、工具调用次数、积分、耗时；
  - 逐步骤：每行一次模型调用，含时间、所属轮次、工具名、参数摘要、模型、输入/缓存/输出 token、该步积分、与上一步的间隔。
- **表头排序**：点列名排序，三态循环（降序 → 升序 → 原始顺序），带 ▲/▼ 指示。
- **「工具 / 动作 × 消耗」可视化**：左侧按工具聚合（点击某工具即筛选明细），右侧按轮次堆叠展示各工具消耗，口径可切 积分 / Token / 次数。
- **CSV 导出**：跟随当前视图与排序。
- **深链**：`/#steps` `/#credit` `#hit` 直达视图；`?task=<会话ID>` 直达某个任务。

## 快速开始

需要 **Python 3.8+**（只用标准库，无需 pip 安装任何东西）。

| 平台 | 启动方式 |
| --- | --- |
| Windows | 双击 `start.bat` |
| macOS / Linux | 终端执行 `./start.sh` |
| 任意平台 | `python wb_usage_server.py` |

启动后自动打开 <http://127.0.0.1:8787/>，关闭窗口即停止。

> `wb_usage_server.py` 是**单文件可执行体**（HTML 已内嵌），只拷这一个文件也能跑。`index.html` 存在时会优先加载它，方便改样式。

## 命令行参数

| 参数 | 说明 |
| --- | --- |
| `--port 9000` | 换端口，默认 8787 |
| `--days 30` | 只统计最近 N 天的任务，默认全部 |
| `--no-open` | 不自动打开浏览器 |
| `--home <目录>` | 指定 WorkBuddy 数据目录，默认 `~/.workbuddy` |

## 数据从哪来

工具只读两处本机文件：

1. `~/.workbuddy/projects/<工作区>/<sessionId>.jsonl`
   每次模型调用的条目带 `providerData.rawUsage`，含 `prompt_tokens`、`completion_tokens`、缓存命中 token 与 `credit`，并附 `conversationRequestId`、模型名、时间戳、工具名。
2. `~/.workbuddy/workbuddy.db`（SQLite，只读打开）
   `sessions` 提供任务标题、工作目录、模型；`session_usage.credit_json` 提供按请求归档的积分。

按 `(messageId, stepSeq)` 去重，避免重复计费；积分以数据库归档为准，缺失时回退到 transcript 累计。抽样比对两者合计多数任务完全一致，个别差异来自图片生成等非模型步骤，取较大值补齐。

## 隐私

- 全部数据留在本机，工具不发起任何外部网络请求，只监听 `127.0.0.1`。
- 数据库以只读方式打开（`mode=ro`），不会写入或改动 WorkBuddy 的任何文件。

## 限制

- 远程 / 云端执行的任务（`transport != local`）不落地到本地 jsonl，看不到；本机执行的任务都是实时的。
- Windows 下若 8787 端口被占用，用 `--port` 换一个即可。
- 明细表单次最多渲染 3000 行以保证流畅，完整数据请用 CSV 导出。

## 目录

```
wb_usage_server.py   单文件本体：本地 HTTP 服务 + 内嵌页面（仅标准库）
index.html           页面源码（存在时优先加载，便于改样式）
start.bat            Windows 启动脚本
start.sh             macOS / Linux 启动脚本
```
